# ROAD-71 thread-chat-workflow

Begin frame-change immediately after ROAD-33 completes. Do not start implementation or promote exploratory notes into approved requirements before that frame.

The operator's direction is a Delta-inspired thread chat with comments as a core feature. MILE-13 groups the common workflow, existing ROAD-60 comments, ROAD-72 context/invocations and ROAD-73 terminal interaction. See [milestone intent and research findings](../milestones/MILE-13.notes.md).

The frame must settle the observable daily workflow and scope first: what a thread preserves; native resume versus a fresh session with prior context; selected context and draft visibility; comment cancellation and delivery while busy; inline terminal before the first message; and ownership boundaries with existing composer, harness discovery, fork and deferred edit/regenerate work.

Only comments as core, the Delta reference, unchanged ROAD-33 scope and post-ROAD-33 timing are fixed by this planning request. Storage shapes, API methods, numerical budgets, default inclusion rules and detailed UI behavior remain design decisions.
